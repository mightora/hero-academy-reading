# Contributing

Open an issue or submit a focused pull request explaining the problem, resulting behaviour and verification.

- Serve `dist/` locally; run `npm test` after changes.
- Check interface changes on a narrow touch screen, with keyboard input and reduced motion.
- Keep child instructions short and picture-led; speech remains on demand.
- Preserve older backups and keep assisted completion distinct from independent practice.
- Explain learning objectives and specialist review for reading-content changes. Do not introduce unreviewed phoneme audio or unsupported diagnostic/effectiveness claims.
- Use original artwork or clearly documented permissions; avoid imitating existing superhero characters.
- Update the service-worker cache version for cached-file changes, and its asset list for new files.

Editable source intentionally lives in `dist/`; do not ignore that directory. No open-source licence has been selected yet.
