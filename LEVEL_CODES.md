# Level codes

Choose **Code** below the adventure map, or **Grown-ups → Enter a level code**. Type a code and choose **Go**.

Codes are case-insensitive. Spaces and a hyphen are accepted, so `hero01`, `HERO01` and `HERO-01` open the same level.

| Code | Level |
| --- | --- |
| `HERO01` | 1 — Suit up! |
| `HERO02` | 2 — Send a signal |
| `HERO03` | 3 — Find the lost kit |
| `HERO04` | 4 — Boots on the ground |
| `HERO05` | 5 — Light the workshop |
| `HERO06` | 6 — Meet your sidekick |
| `HERO07` | 7 — Fix the scanner |
| `HERO08` | 8 — Grow your base |
| `HERO09` | 9 — Cape connection |
| `HERO10` | 10 — Robot roll call |
| `HERO11` | 11 — The missing map |
| `HERO12` | 12 — Academy rescue |

A code opens a level even if its usual prerequisite is unfinished. It does not complete skipped levels, grant their rewards or erase progress. Completing the selected level records the actual responses and completion normally. Codes are navigation shortcuts, not authentication or proof of reading ability.
